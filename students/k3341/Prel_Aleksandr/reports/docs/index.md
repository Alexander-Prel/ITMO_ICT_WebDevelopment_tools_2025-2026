# Web Development Tools

**Прель Александр, K3341. Учебный год 2025-2026.**

Тема: разработка веб-приложения для буккросинга.

В отчёте представлены [лабораторная работа 1](lab1.md),
[практики 1.1-1.3](practices.md), описание модели данных и финальный код.
Отдельный раздел посвящён [лабораторной работе 2](lab2.md): суммированию
и парсингу с потоками, процессами и asyncio. Парсинг измерен; новый
CPU-эксперимент `10^10` завершён 21 сентября без обнаруженного системного сна.
Исходное задание требует `10^13`; согласование уменьшенного диапазона
преподавателем не подтверждено.
Приложение реализует API; опубликованный сайт является документацией,
а не запущенным backend-сервисом.
