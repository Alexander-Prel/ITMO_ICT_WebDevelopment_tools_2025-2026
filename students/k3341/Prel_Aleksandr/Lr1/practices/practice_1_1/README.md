# Практика 1.1. FastAPI и Pydantic

[Задание](https://rendex85.github.io/WebDevelopmentLabsDocs/lr2/pr1/).

Самостоятельное приложение с временным хранилищем в памяти. Реализованы
CRUD книг и авторов, создание и список жанров, проверка входных данных,
возврат вложенного автора и списка жанров у книги.
Связанный с книгой автор не удаляется; неизвестные связи возвращают 404.
Изменения теряются после перезапуска.

Модели находятся в `models.py`, маршруты и фабрика приложения в `main.py`.
В отличие от этой упрощённой модели, итоговая ЛР1 хранит автора строкой.

Из корня `Lr1` после установки зависимостей:

```bash
python -m uvicorn practices.practice_1_1.main:app --port 8011
```

[Swagger UI](http://127.0.0.1:8011/docs).
