# Практика 1.2. PostgreSQL и SQLModel

[Задание](https://rendex85.github.io/WebDevelopmentLabsDocs/lr2/pr2/).

Отдельная точка входа `main.py` использует фабрику `../database_app.py`.
Таблицы создаются через `SQLModel.metadata.create_all()` в схеме
`practice_1_2`, отдельно от основной схемы `public`.

Модели, схемы ответов, роутеры и сервисы повторно используются из `app/`.
Связь книга-жанр реализует many-to-many и отдельное удаление связи.
Связь пользователь-книга представлена сущностью `LibraryItem`, которая
дополнительно хранит состояние, статус и комментарий. Ответ книги
содержит вложенные жанры, создателя и экземпляры.

После настройки PostgreSQL и `.env` по основному README, из корня `Lr1`:

```bash
python -m uvicorn practices.practice_1_2.main:app --port 8012
```

[Swagger UI](http://127.0.0.1:8012/docs). Папка практики является отдельной
точкой входа, а не автономной копией всех зависимостей приложения.
